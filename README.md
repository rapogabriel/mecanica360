# Mecânica360

> Projeto fictício desenvolvido para a disciplina de Engenharia de Software I - Curso de Ciência da Computação da Universidade Federal de Ouro Preto (UFOP).

## Sobre o Projeto

O **Mecânica360** é um software de gerenciamento completo voltado para oficinas mecânicas. Seu principal objetivo é otimizar a rotina do estabelecimento, centralizando informações e facilitando o controle das operações diárias, desde a chegada do cliente até a análise de desempenho do negócio.

## Funcionalidades Principais

- **Organização de Atendimentos:** Controle do fluxo de clientes e agendamentos da oficina.
- **Acompanhamento de Ordens de Serviço (OS):** Monitoramento prático do status de cada serviço em andamento.
- **Gestão de Disponibilidade:** Coordenação da escala de mecânicos e controle da alocação de recursos e equipamentos.
- **Indicadores Operacionais:** Análise de dados e métricas para auxiliar na tomada de decisão e gestão do negócio.
